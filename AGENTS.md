# Project continuity

At the start of work in this repository:

1. Read [MEMORY.md](MEMORY.md) for the user's preferences, current architecture, deployment state, and operational details.
2. Read the latest entries in [CHANGELOG.md](CHANGELOG.md) for implementation history and regression fixes.
3. Use [README.md](README.md) and the current code as the implementation reference. The original master specification and orchestration plan are historical; their API-generation approach has been superseded.

Preserve the Reddit-style design the user explicitly approved. The product is a leisure-first scrolling feed with occasional engineering review, rather than a coursework dashboard.

After substantial changes, update the change log and revise the memory's current-state sections. Date snapshots and distinguish implemented behavior, verified results, and future ideas. Never put credentials, tokens, or private source documents in these logs.
